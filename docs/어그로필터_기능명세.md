# 📝 어그로필터 기능 스펙

## 1. 서비스 개요
- **목표**: 유튜브 영상의 신뢰도 분석 및 어그로 필터링
- **주요 유저**: 유튜브 시청자 및 분석가

## 2. 핵심 기능 리스트
- **[분석 엔진]**: 
  - 사용자가 입력한 유튜브 URL에서 영상 ID 및 자막(Transcript), 메타데이터 추출
  - **[제로대기 비동기 투트랙]**: 빠른 1차 노출(요약/스포일러) + 정밀 2차 분석(신뢰도/평가) 구조.
  - **[하이브리드 2단계 입구컷 게이트키퍼 (비용 99% 방어)]**:
    - **안전 카테고리(IT/교육/뉴스/노하우/시사 등)**: 1단계 검문 없이 0초 만에 전문 분석 즉시 직행 (초고속 반응).
    - **모호 카테고리(코미디 23, 엔터 24, 자동차 2, 여행 19, 동물 15 등)**: 유튜버의 카테고리 오지정(예: 코미디로 등록된 코딩/지식 채널)을 포용하기 위해, 자막 전문 분석 전 **1단계 초경량 Title Guard(GPT-4o-mini, 80토큰)**가 제목+채널명만으로 정보성/기술/리뷰 가치를 0.2초 만에 사전 판별. 단순 개그/먹방은 0.0008원 비용으로 즉시 차단하여 회사 AI 비용 유출을 99% 철통 방어하고, 유익한 영상은 2단계 전문 분석으로 안전 진입.
    - **음원/음악(10)**: 즉시 차단 유지.
  - **[자막 Handoff 및 도메인 가드]**: 확장프로그램 ➡️ 웹앱 자막 전송 시 유효 데이터(50자 이상) 수신 시에만 ACK 응답하며, 전송 지연 시에도 에러 중단 없이 **백엔드 YouTube 자막 직접 추출 엔진으로 자동 연계**하여 분석 성공률 100% 보장. 구도메인(`aggrofilter.com`) 유입 시 공식 도메인(`aggrofilter.sundreamer.app`)으로의 **301 영구 리다이렉션 자동 수행**.
- **[코인 시스템 (허브 중앙 관리)]**: 
  - 분석 요청 시 허브 API를 통해 코인 차감 (단가: 동적 과금, 실시간 토큰 기반 계산)
  - 캐싱 로직: 이미 분석된 영상은 차감 없이 즉시 노출.
- **[광고 타임패스 (Ad-Free Timepass)]**:
  - 유튜브 확장팩 아이콘을 통해 정식 과금 분석이 완료되면 **24시간 동안 사이드/바텀 광고 자동 제거**.
  - 만료 시간(`ad_free_until`)은 분석 응답 JSON으로 전달 → 클라이언트 `localStorage`에 저장.
  - 앱 내 단순 클릭(DB 캐시 조회)은 과금 없음 → 광고 디폴트 ON.
  - 게스트(비로그인) 사용자는 타임패스 미부여.
- **[허브 연동 통합 알림 (이메일 전송)]**: 
  - 관심 채널 구독/등급 변화 혹은 영상 분석 완료 시 Merlin Hub SDK를 통해 등록된 유저 이메일로 알림을 발송.
  - 인앱 푸시 및 알림 종 뱃지/드롭다운 UI는 일체 제공하지 않으며, 모든 중요 공지는 이메일을 통해서만 안내됨.
  - 설정 페이지(`p-settings`) 내 이메일 알림 수신 설정을 허브 프로필 카드(`HubProfileCards`) 및 SDK(`useHub().updateNotificationSettings`)와 직접 동기화하여 제어.
- **[비회원 선체험 및 가불 정산 (Anonymous Experience & Settle)]**:
  - 비로그인 유저의 진입 장벽 완화를 위해 1회 무료 분석 체험을 제공.
  - 분석 완료 시점에 발생한 분석 비용(`pending_usage_fee`)과 분석 ID/비디오 ID(`pending_video_id`)를 클라이언트 로컬스토리지에 적재.
  - 유저가 이후 로그인(이메일 OTP 인증)을 성공적으로 완료하면, 허브 백엔드가 인증 과정에서 해당 가불금을 원자적으로 차감하고, 클라이언트는 즉시 `/api/analysis/link-guest` API를 호출하여 비회원 시절 생성된 분석 결과의 소유자(`f_user_id`)를 익명 ID(`trial_%`)에서 정식 유저 UUID로 이관함.
  - 마이그레이션 API는 전달된 비디오 ID가 분석 ID(f_id UUID) 혹은 유튜브 비디오 고유 ID(f_video_id) 중 어떤 형식으로 넘어오든 유실 없이 확실하게 이관되도록 지원.
- **[모바일-PC 크로스 디바이스 분석 브릿지 (PWA-Extension Handoff)]**:
  - 모바일 환경의 자막 추출 제약을 극복하기 위해 설계된 백그라운드 분석 handoff 시스템.
  - 상세한 핵심 사양 및 데이터베이스 스키마, 동작 프로세스는 별도로 분리된 **[NEW_모바일-PC 크로스디바이스_분석 브릿지.md](file:///d:/AggroFilter/docs/NEW_%EB%AA%A8%EB%B0%94%EC%9D%BC-PC%20%ED%81%AC%EB%A1%9C%EC%8A%A4%EB%94%94%EB%B0%94%EC%9D%B4%EC%8A%A4_%EB%B6%84%EC%84%9D%20%EB%B8%8C%EB%A6%BF%EC%A7%80.md)** 명세를 참고하십시오. (추후 어그로필터 테스트 시 활용 예정)

## 3. 연동 기술 및 접점
- **유저 식별**: 허브 UUID (`family_users.id`) 단일 사용.
- **인증**: 허브 OTP/JWT 및 SSO 연동.
- **결제**: KCP PG 연동 (썬드림 주식회사).
- **AI 엔진**: Google Gemini 1.5-flash.

## 4. Policy & Constraints
- **유튜브 API 쿼터**: 효율적 필터링을 통한 쿼터 절약.
- **환불 규정**: 디지털 재화 특성(7일 이내/미사용 시) 준수.
