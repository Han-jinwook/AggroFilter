# ⚡ 제로대기 비동기 AI 투트랙 & 대기열 연동 스펙

## 0) 목표
- 사용자가 분석 시작 직후 **기다리는 느낌 없이** 결과 페이지를 보도록 전환한다.
- AI 처리를 2개 트랙으로 분리해, **빠른 1차 노출(요약/스포일러 1.3초) + 정밀 2차 완성(신뢰도/평가 10초)** 구조로 운영한다.
- 로컬 워커 미가동 시에도 화면이 멈추거나 튕기지 않고 **202 대기열 등록 안심 카드**를 즉시 제공한다.

---

## 1) 투트랙 운영 원칙

### Track A (정밀 분석)
- `app/api/analysis/request/route.ts` 및 `lib/gemini.ts` 중심.
- 신뢰도/어그로/정확성 점수 산출 및 팩트체크 선행 검색(Grounding) 연계.
- 완료 시 `processingStage = completed`로 마감하고 DB 저장.

### Track B (속도 분석)
- 자막 및 메타데이터 기반 썸네일 스포일러와 3줄 요약을 우선 생성.
- 사용자가 체감하는 진입 속도를 1.3초 수준으로 극대화.
- `speed_ready` 단계 데이터 우선 렌더링.

---

## 2) 3단계 UX 작전 & [B안] 대기열 처리

### 1단계: 결과 페이지 즉시 진입 + 영상 카드 우선 노출
- 모바일 공유 또는 웹 검색창 입력 즉시 결과 페이지(`/p-result?id=...` 또는 `url=...`)로 직행.
- 상단 유튜브 썸네일과 제목 카드를 즉시 렌더링.

### 2단계: 1.3초 후 Speed 트랙 요약/스포일러 노출
- 자막 획득 즉시 요약/스포일러 렌더링.
- 정밀 채점이 진행 중임을 부드러운 스켈레톤/로더로 인지시킴.

### 3단계: Completed 수신 후 정밀 신뢰도 점수 카드 노출
- 10초 내 `completed` 수신 즉시 신호등 점수 카드(녹/황/적) 및 평가 사유, 착한 제목 추천 렌더링.

### [B안] 워커 오프라인/지연 시 대기열 카드 전환
- 12초 내 자막 미도달 시 에러 실패가 아닌 **202 Queued** 응답 처리.
- "⏳ 분석 대기열에 등록되었습니다 | 🛡️ 코인은 차감되지 않았습니다" 전용 카드 노출.
- 워커 가동 시 백그라운드 자동 완주 ➔ Merlin Hub 이메일 알림 연동.
