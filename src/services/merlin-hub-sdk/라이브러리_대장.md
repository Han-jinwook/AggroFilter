## 📜 2. 최근 메이저 업데이트 이력

### [v2.0.0] 2026-08-26: 서브도메인 공용 쿠키 SSO & 멀티탭 실시간 동기화
1. **서브도메인 공용 쿠키 (`.sundreamer.app`) 엔진 탑재 (`client.ts`)**:
   - `localStorage`의 서브도메인 격리 한계를 극복하기 위해 `setSessionToken()` 시 `domain=.sundreamer.app; max-age=2592000` (30일) 쿠키를 자동 동시 발급.
   - `getSessionToken()` 호출 시 `localStorage`가 비어 있어도 공용 쿠키에서 즉시 토큰을 읽어와 자동 복원.
2. **다중 탭 실시간 세션 동기화 (`HubProvider.tsx`)**:
   - `visibilitychange`, `focus`, `storage` 이벤트 리스너를 탑재하여, 한 탭(예: 뭐먹지)에서 로그인/로그아웃 시 다른 탭(예: 썬드리머)으로 전환하는 즉시 새로고침 없이 세션이 100% 실시간 동기화되도록 구현.
3. **인증 모달 혜택 분기 (`HubAuthModal.tsx`)**:
   - `rewardType?: 'coin' | 'point' | 'none'` 지원 추가로 썬드리머 전용 **5,000 포인트 배지** 지원.
4. **Vite / Next.js 크로스 플랫폼 무결성 확보**:
   - `HubAppSwitcher.tsx`의 이미지/아이콘 타입 및 `HubResponsiveWing.tsx`의 `next/navigation` 종속성 제거 완료.
