## 📜 2. 최근 메이저 업데이트 이력

### [v2.9.8] 2026-09-12: 앱별 독립 세션 보장 및 단독 로그아웃 격리 (Local Token Shield)
1. **CoreLogic `clearSessionToken` 스코프 분리 (`client.ts`)**:
   - `clearSessionToken(scope: 'local' | 'global' = 'local')` 도입.
   - 단독 앱 로그아웃 시 `.sundreamer.app` 최상위 공용 쿠키를 삭제하지 않고 보존하여 타 패밀리 앱의 세션 연쇄 파괴를 원천 차단.
   - 명시적 로그아웃 앱에는 `merlin_logged_out = '1'` 플래그를 두어 공용 쿠키로부터의 원치 않는 자동 재로그인 방지.
2. **CoreLogic `getSessionToken` 자가 치유(Self-Healing) 탑재 (`client.ts`)**:
   - 로컬스토리지에 유효한 세션 토큰이 존재하나 공용 쿠키가 유실된 경우, 로컬 토큰을 기반으로 `.sundreamer.app` 도메인 쿠키를 자동 복원.
3. **HubProvider `Local Token Shield` 강화 (`HubProvider.tsx`)**:
   - 다른 탭 활성화 감시 시, 타 앱의 로그아웃 여파로 공용 쿠키에 변동이 생기더라도 현재 앱 자체의 로컬스토리지에 토큰이 살아있다면 세션을 강제 종료하지 않고 30일 동안 안전 유지.
4. **Session `HubLogoutCard` 로컬 격리 파기 (`HubProfileCards.tsx`)**:
   - 로그아웃 클릭 시 `.sundreamer.app` 공용 도메인 쿠키 강제 만료(max-age=0) 코드를 제거하고, 현재 호스트 세션만 안전 파기하도록 단일화.
5. **Auth `logout` 인터페이스 확장 (`auth.ts`)**:
   - `logout(scope: 'local' | 'global')` 지원으로 앱별 단독 로그아웃 기본 동작 보장.
6. **Hub Backend DB 장애 시 세션 보호 (`auth.service.ts`)**:
   - `/api/auth/me`에서 일시적인 DB 지연/에러 발생 시 401(계정 미존재로 오판하여 세션 영구 파기) 대신 500 에러를 반환하여 클라이언트가 캐시된 로그인 세션을 안전하게 보존하도록 방어.
1. **Wallet 결제 상품명 확장 (`useHubPayment.ts`, `wallet.ts`)**:
   - `requestPayment` 및 `requestKcpPayment`에 `productName` 옵셔널 파라미터 추가.
   - 코인 충전 외에 온라인 스토어 실물 제품명(예: `스탠드형(ST-1512) 1대 + 멀티거치형(FT-1801) 1대`)이 KCP 결제창 상단 `good_name`에 100% 정확하게 표출되도록 지원.

1. **CoreLogic `sendNotification` 확장 (`client.ts`)**:
